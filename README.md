# My Base Quest 🚀

## ✨ Overview
A simple but polished counter app built to practice JavaScript fundamentals, UI design, and user experience improvements.

Users can increment, decrement, reset, and switch between light/dark mode, with all data saved locally.

---

## 📖 About
This repo documents my journey exploring Base mini apps, USDC farming, and learning web3 development.  
I share experiments, insights, and progress along the way.

---

## 📱 Mini App: Counter App
I built a simple interactive counter app as part of my learning.

### 🚀 Features
- Increase (+1) and decrease (-1) counter
- Reset counter
- Prevent negative values
- Disable decrement button at zero
- Persist counter using localStorage
- Dark mode toggle 🌙
- Save dark mode preference
- Clean card-style UI

### 🛠️ Technologies Used
- HTML  
- CSS  
- JavaScript  

### 📦 How to Run
1. Clone or download this repository  
2. Open the project folder  
3. Open `index.html` in your browser
